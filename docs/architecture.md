# KAVACHGRID 3.0 — Architecture Documentation

> Phase 16: Complete documentation

## System Overview

KAVACHGRID 3.0 is an AI-Powered Energy Theft, Anomaly Detection, Risk Ranking & Progressive Localization System.

It is an **Investigation Support System** — it does NOT claim to automatically prove theft.

## Architecture Layers

1. **Field Layer** — ESP32 + Sensors (INA219/INA226)
2. **Communication Layer** — MQTT Broker (Mosquitto + TLS)
3. **Backend Layer** — FastAPI REST API + Services
4. **Analytics Layer** — 6 Analytics Engines
5. **Data Layer** — PostgreSQL
6. **Presentation Layer** — Next.js Dashboard
